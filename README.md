# PROYECTO-INTEGRADOR
# Calculadora de Volúmenes de Figuras Geométricas

Proyecto integrador de la carrera técnica de software.  
Aplicación web para calcular el volumen de figuras geométricas con visualización y rotación de las figuras usando HTML, CSS y JavaScript.

## Estado actual del proyecto

- [x] Diseño de mockups / prototipos
- [ ] Estructura HTML
- [ ] Estilos CSS
- [ ] Lógica de cálculo (JavaScript)
- [ ] Rotación de figuras
- [ ] Diseño responsivo
- [ ] Pruebas y documentación final

## Descripción del proyecto

Esta aplicación permitirá al usuario seleccionar una figura geométrica (cubo, esfera, cilindro, cono, etc.), ingresar las medidas necesarias y obtener el volumen. Además, las figuras podrán rotar para una mejor visualización.

## Framesworks a utilizar

- HTML5
- CSS3
- JavaScript (Vanilla)
